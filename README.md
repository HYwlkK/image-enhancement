# image-enhancement 漫像交融

面向普通用户的照片动漫化与基础增强Web应用，第3组课程项目。

## 当前状态
需求与协作准备阶段，尚无可运行版本。以下为计划功能。

## 首版
- P0：单张JPEG/PNG上传、1种动漫风格、状态、对比、下载、隔离与清理。
- P1：基础增强和组合模式、风格预设、当前会话最近记录。
- 不包含视频、训练、反向真人化、超分辨率、付费与社交。

## 环境与启动
拟用Vue 3前端、FastAPI后端及OpenCV/Pillow通用库，从零实现平滑、量化、边缘提取和融合。版本在T01/T05验证后锁定。
当前不能启动，不提供未经验证的运行命令。M1补充依赖锁定、算法参数、安装启动、访问URL、停止及排错方法。
README启动方式需经组外同学实际复现，随后登记真实记录。

## 使用流程
上传 → 模式与参数 → 提交 → 状态 → 对比 → 下载/删除。
单张≤10MiB、≤2000万像素，处理最长边1920像素。

## 自主开发与许可
本项目由第3组从零设计和开发，首版实现基于平滑、色彩量化、边缘提取和融合的动漫风格化流程，不使用预训练权重。
本项目沿用仓库已有的[MIT许可证](LICENSE)；通用依赖按各自许可使用。
项目文档由第3组统一维护，成员分别核对负责章节；代码提交须附测试结果。
